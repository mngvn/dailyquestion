# dailyquestion

A spider's web in the wind. Every fly that blunders into it is carrying a fun
fact — click one to read it. Click the spider for the games it keeps.

Plain static files, served from the repo root (GitHub Pages).

| File | What it is |
| --- | --- |
| `index.html`, `home.css` | The home page and what is laid over the web: the date, the fact card, the spider's larder |
| `orb.js` | Puts it all together: the frame loop, the pointer, the card and the menu |
| `silk.js` | The web: how it is strung, its physics, how it is drawn |
| `scene.js` | The wind, the sky, and the plants the web hangs from |
| `spider.js` | The spider |
| `flies.js` | The flies, and the parcels they end up as |
| `app.js`, `deck.js`, `data.js` | Today's facts, dealt by date |
| `boat.js`, `boat.css` | Adrift, the leaking-rowboat game, laid over the home page |
| `sun.*`, `orbit.*`, `park.*`, `cave.*` | The other games, each a page of its own |
